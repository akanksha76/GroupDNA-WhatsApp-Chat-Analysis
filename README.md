# 📊 GroupDNA – WhatsApp Chat Analysis

## 📌 Project Overview

GroupDNA is a Python-based WhatsApp Chat Analyzer that extracts useful insights from an exported WhatsApp group chat using Python Fundamentals and NumPy.

This project was developed as part of my Python Fundamentals Mini Project.

---

## ✨ Features

- 📂 WhatsApp Chat Parsing
- 👥 Group Overview
- 📈 Activity Analysis
- ⏰ Hourly Activity Analysis
- 🔥 Peak Activity Detection
- 📝 Word Frequency Analysis
- ⚡ Response Speed Analysis
- 🌙 Silent Streak Detection
- 🎭 Personality Archetype Detection
- 📊 Final Summary Report

---

## 🛠️ Technologies Used

- Python
- NumPy
- Google Colab
